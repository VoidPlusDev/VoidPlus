📥 Install VoidPlus

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/VoidPlusDev/VoidPlus/main/install.sh | bash
```

📦 Install Package
```bash
apt install box64-custom
```

🗑 Remove Package
```bash
apt remove box64-custom
```
